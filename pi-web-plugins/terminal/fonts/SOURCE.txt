JetBrains Mono Nerd Font Mono

Source: https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/JetBrainsMono/Ligatures
Nerd Fonts: 3.5.1; JetBrains Mono: 2.304
Styles: Regular, Bold, Italic, BoldItalic
License: SIL Open Font License 1.1; see OFL.txt and NERD-FONTS-LICENSE.

Each upstream TTF was losslessly compressed to WOFF2 using Google woff2_compress.
No glyph subsetting or font metadata changes were applied.
Reproduce: woff2_compress JetBrainsMonoNerdFontMono-<Style>.ttf

The application uses the CSS family alias "PI Web Terminal" to ensure the bundled
font is used instead of a potentially different locally installed version.
Assets are served with the plugin; normal builds do not download or convert fonts.
